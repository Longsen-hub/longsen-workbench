# 评论区健康诊断（免费版）

## 定位

ABSA（Aspect-Based Sentiment Analysis）方面级情感分析——**不满足于「这条评论是正面/负面」的粗分**，而是识别评论**具体在说哪个方面**，并对每个方面独立判定情感强度。

## 为什么需要方面级分析

一条评论可以同时包含多个方面：
> 「这猫粮太贵了，但猫猫爱吃」→ 价格价值（负面）+ 宠物养护（正面）

粗分引擎只会给一个整体情感，会丢失关键信息；方面级分析才能定位「到底哪里出了问题/哪里值得放大」。

## 11 方面框架（免费版）

| 方面 | 关注什么 |
|:---|:---|
| 内容质量 | 好看/精彩/干货/专业度 |
| 价格价值 | 贵/便宜/性价比/值不值 |
| 萌点颜值 | 可爱/漂亮/颜值 |
| 剧情主题 | 剧情/反转/套路/设定 |
| 互动体验 | 点赞/收藏/催更/更新 |
| 服务售后 | 客服/物流/发货/态度 |
| 情感共鸣 | 泪目/破防/治愈/真实 |
| 宠物养护 | 猫粮/疫苗/绝育/养护 |
| 仪式话题 | 办酒席/满月/彩礼/红包 |
| 外观体态 | 胖/毛色/体型/花纹 |
| 行为习性 | 撒娇/粘人/拆家/高冷 |

## 情感强度 5 级

| 级别 | 示例 |
|:---|:---|
| 强烈正面 | 绝绝子/yyds/吹爆/天花板 |
| 温和正面 | 喜欢/不错/赞/满意 |
| 中性 | 无情感词 |
| 温和负面 | 一般/失望/无语 |
| 强烈负面 | 垃圾/骗人/退钱/避雷 |

## 基础分析流程（免费版可执行）

1. 每条评论 → 命中方面（可多命中）
2. 每个方面 → 独立情感判定（5级）
3. 低置信（无词命中）→ 标注人工复核
4. 汇总 → 方面×情感矩阵 + 负面最多方面（痛点）+ 需求型评论数 + 互动建议

## 示例输出

```
输入：3 条评论
  A「这猫粮太贵了，但猫猫爱吃」
  B「绝绝子！求同款链接」
  C「垃圾，退钱！」

输出：
  方面矩阵：价格价值(负面1) / 宠物养护(负面1) / 其他(强正1) / 其他(强负1)
  痛点：价格价值（1条负面，样本：这猫粮太贵了…）
  需求：1 条需求型评论（求链接）→ 建议引导私信承接
  建议：优先处理负面方面 + 承接需求型评论
```

> 说明：规则引擎对整条评论判定 5 级情感后映射到全部命中方面（如 A 评论整体为负面，价格价值与宠物养护均计负面）；每个方面独立判定情感（纯 ABSA）可由大模型深度版实现。

## 边界与降级（异常处理）

| 场景 | 处理 |
|:---|:---|
| 评论无任何词命中 | 归为「其他」方面，低置信（<0.6）→ 标注需人工复核 |
| 无行业词库 | 使用内置 11 方面词典，不阻塞分析 |
| 评论过短（≤2字） | 置信度 0.3，不参与高置信样本选取 |
| 需求型与负面并存 | 需求仍计数，互动建议同时给承接与安抚 |
| 大模型深度版不可用 | 纯规则引擎保底，输出自动标注低置信清单 |

## 检查点

- 批量分析前：确认评论文本无隐私泄露（昵称/联系方式可脱敏）
- 报告交付前：低置信评论（confidence<0.6）由人工复核后再定论
