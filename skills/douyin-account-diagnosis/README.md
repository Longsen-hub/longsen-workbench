# 抖音账号健康体检（douyin-account-diagnosis）

抖音账号四维度量化诊断引擎：账号体量(35) + 内容表现(35) + 运营活跃度(20) + 平台指数(10) = 100 分。

## 它能做什么

- 输入抖音昵称或抖音号 → 输出 100 分制四维评分 + 诊断报告
- 评分明细可追溯（每个指标怎么算的，一目了然）
- 自动生成优势/短板分析 + ≥3 条优先级排序的优化建议
- S/A/B/C/D/E 六级评级，横向可比

## 本发布包内容

本发布包为**方法论完整版文档**：

```
├── SKILL.md   # 四维度评分体系完整方法论（每指标分段得分表）/ 评级标准 / 优势短板建议规则 / 诊断报告结构 / 兼容性边界
└── README.md  # 本文档
```

> 数据服务API接入与自动化脚本由集成方按 SKILL.md 方法论落地；完整可运行实现见「全能版」配套能力。

## 集成方式

1. 获取数据服务API Key（格式 `ak_xxx`），配置环境变量 `OPC_HUB_API_KEY`
2. 按 SKILL.md 四维评分表逐项打分（每项附计算过程，可追溯）
3. 汇总综合评分 → 对照评级表定级 → 输出优势/短板/建议
