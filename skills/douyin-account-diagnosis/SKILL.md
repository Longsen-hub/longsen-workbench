# 抖音账号健康体检（douyin-account-diagnosis）

## 简介

基于数据服务API的抖音账号四维度量化诊断引擎。告别主观判断，用统一评分标准横向比较账号健康度。

通过简单的账号输入，你可以：
- 📊 获取四维度量化评分（100分制）
- 📋 自动生成评分计算明细 + 完整诊断报告
- 💡 获得针对性的优势/短板分析和优化建议

适用于品牌方、MCN机构、自媒体从业者、内容运营人员等需要评估抖音账号表现的场景。

**触发方式：**
- "诊断抖音账号"、"抖音账号分析"、"抖音体检"、"抖音评估"
- 直接输入抖音名称 + "诊断/分析"

## 功能特性

| 功能 | 说明 |
|------|------|
| 📊 四维度评分 | 账号体量(35分) + 内容表现(35分) + 运营活跃度(20分) + 平台指数(10分) = 100分 |
| 📋 诊断报告 | 评分计算明细 + 完整诊断报告（基本信息/核心数据/综合评分/优化建议） |
| 🔍 账号查询 | 支持按昵称（模糊匹配）或抖音号（精确匹配）查询 |

### 特色亮点

- **⚡ 精准数据**：基于数据服务API接口，所有数据来源可追溯，严禁估算编造
- **📈 标准化评分**：统一的评分标准，横向可比，避免主观判断
- **🔧 兼容null值**：播放量为null时不影响评分，传播系数使用分享/点赞比替代
- **🏷️ 分类映射**：API返回的账号分类自动映射为统一输出名称

## 前置条件

### 数据服务API Key

- 已获取数据服务API Key（前往数据服务API控制台申请，格式 `ak_xxx`）
- 环境变量：`OPC_HUB_API_KEY`（数据服务API访问密钥）
- 可选：`OPC_HUB_BASE_URL`（数据服务API地址，默认使用官方地址）

### 环境变量配置

| 变量名 | 必填 | 说明 |
|--------|------|------|
| `OPC_HUB_API_KEY` | ✅ | 数据服务API密钥（ak_xxx 格式） |
| `OPC_HUB_BASE_URL` | ❌ | 数据服务API地址（默认官方） |

## 四维度评分体系（100分制）

### 设计原则

1. **仅依赖API可返回字段** — 所有指标均来自API返回数据
2. **兼容播放量为null** — 不将播放量作为必要计算因子
3. **0换算** — 每项直接评分，无需乘系数/换算
4. **不重复** — 同一指标只在一个维度出现

### 维度一：账号体量（35分）

**评估账号的基础规模和粉丝价值**

| 指标 | 满分 | 评分标准 | 数据来源 |
|------|------|---------|---------|
| 粉丝数 | 22分 | 见下表 | followerCount |
| 获赞总数 | 8分 | 见下表 | totalFavorited |
| 获赞/粉丝比 | 5分 | 见下表 | totalFavorited/followerCount |

| 得分 | 粉丝数 | 量级 |
|------|--------|------|

| 16分 | 500-1000万 | 准头部 |
| 12分 | 100-500万 | 中腰部 |
| 9分 | 50-100万 | 中小 |
| 5分 | 10-50万 | 小型 |
| 2分 | 1-10万 | 微型 |
| 0分 | <1万 | 新号 |

#### 获赞总数评分（8分）

| 得分 | 获赞数 |
|------|--------|
| 8分 | ≥10亿 |
| 6分 | 1-10亿 |
| 5分 | 1000万-1亿 |
| 3分 | 100-1000万 |
| 1分 | 10-100万 |
| 0分 | <10万 |

#### 获赞/粉丝比评分（5分）

| 得分 | 比值 | 说明 |

| 传播系数 | 6分 | avg(shareCount/diggCount) | 分享/点赞比，衡量自发传播力 |

### 综合评分计算

```
综合评分 = 账号体量(0-35分) + 内容表现(0-35分) + 运营活跃度(0-20分) + 平台指数(0-10分)
```

| 得分 | 评级 | 说明 |
|------|------|------|
| **90-100** | 🏆 S级 | 标杆账号，行业领先 |

| **70-79** | ✅ B级 | 健康账号，有优化空间 |
| **60-69** | 📊 C级 | 中等账号，需重点优化 |

| **<50** | ❌ E级 | 问题账号，急需优化 |

## 优势/短板/建议生成逻辑

### 优势判断（取前2条输出）

| 条件 | 优势文案 |
|------|----------|
| 账号体量≥28 | 账号体量雄厚 |
| 账号体量≥18 | 粉丝基础扎实 |
| 内容表现≥28 | 内容数据突出 |
| 内容表现≥18 | 内容表现良好 |
| 运营活跃度≥16 | 运营节奏健康 |
| 平台指数≥8 | 平台指数优秀 |
| 平台指数≥4 | 平台影响力良好 |
| 以上均不满足 | 有基础运营框架 |

### 短板判断（取前2条输出）

| 条件 | 短板文案 |
|------|----------|
| 账号体量<12 | 账号体量偏小 |
| 内容表现<10 | 近期内容表现较弱 |
| 内容表现==0 | 近7天无作品数据 |
| 运营活跃度<8 | 运营活跃度不足 |
| 平台指数==0 | 无平台指数数据 |
| 以上均不满足 | 整体表现均衡，持续优化即可 |

### 建议生成（按短板优先级，至少3条）

| 条件 | 问题 | 建议 |
|------|------|------|
| 内容表现==0 | 近7天无作品更新 | 恢复稳定发布节奏，建议至少周更2-3条 |
| 内容表现<12 | 内容互动数据偏低 | 优化视频前3秒吸引力，增加互动引导话术 |
| 账号体量<12 | 粉丝基数偏小 | 通过热点内容+投放加速涨粉，聚焦垂直领域深耕 |
| 账号体量<22 | 账号体量有提升空间 | 持续产出爆款内容扩大影响力，探索跨平台引流 |
| 运营活跃度<10 | 运营活跃度不足 | 制定内容排期表保持日更或高频更新，完善账号简介 |
| 运营活跃度<16 | 运营节奏可优化 | 聚焦黄金时段（11-13点/18-21点）发布 |
| 平台指数==0 | 平台指数数据缺失 | 持续稳定运营以积累平台指数 |
| 平台指数<4 | 平台指数偏低 | 提升内容质量与互动率，保持稳定更新 |

## 诊断报告结构

```
一、基本信息   昵称/抖音号/地区/粉丝/获赞/作品数/数据服务指数/采集时间
二、核心数据   近7天作品表现（点赞/评论/分享/传播系数）
三、综合评分   四维度得分 + 总分 + 评级（S/A/B/C/D/E）
四、优势分析   前2条优势（带数据依据）
五、短板分析   前2条短板（带数据依据）
六、优化建议   ≥3条可执行建议（按优先级排序）
七、评分明细   每个指标得分 + 计算过程（可追溯）
```

## 边界与兼容

- 部分账号可能未被数据服务平台收录或数据未更新，此时数据服务指数返回0或null，平台指数维度得0分——不影响其余三维度评分
- 播放量字段为null时不影响评分（传播系数使用分享/点赞比替代）
- 账号分类由API返回后经映射表统一为可读名称
