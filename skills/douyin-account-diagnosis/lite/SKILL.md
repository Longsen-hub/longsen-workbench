# 抖音账号健康体检（免费版）

## 定位

抖音账号四维度量化诊断——用统一评分标准告别主观判断，快速评估账号健康度。

## 四维度评分框架

```
综合评分 = 账号体量(0-35分) + 内容表现(0-35分) + 运营活跃度(0-20分) + 平台指数(0-10分) = 100分
```

| 维度 | 满分 | 评估什么 |
|:---|:---|:---|
| 账号体量 | 35 | 粉丝数/获赞总数/获赞粉丝比（基础规模与粉丝价值） |
| 内容表现 | 35 | 近7天作品平均点赞/评论/分享/传播系数（市场表现） |
| 运营活跃度 | 20 | 更新频率/发布时段/账号完整度/作品总量（运营规范） |
| 平台指数 | 10 | 平台权威指数（影响力） |

## 评级标准（免费版可直接用）

| 得分 | 评级 | 说明 |
|------|------|------|
| **90-100** | 🏆 S级 | 标杆账号，行业领先 |
| **80-89** | ⭐ A级 | 优质账号，竞争力强 |
| **70-79** | ✅ B级 | 健康账号，有优化空间 |
| **60-69** | 📊 C级 | 中等账号，需重点优化 |
| **50-59** | ⚠️ D级 | 亚健康，需要调整 |
| **<50** | ❌ E级 | 问题账号，急需优化 |

## 快速体检流程

1. 获取账号基础数据（粉丝/获赞/作品数/近7天作品表现/数据服务指数）
2. 按四维度逐项打分（免费版按框架定性评估，全能版有精确分段评分表）
3. 汇总综合评分 → 对照评级表定级
4. 输出：评分 + 评级 + 简要优势短板

## 设计原则（免费版也遵守）

1. **仅依赖可返回字段** — 所有指标来自真实数据
2. **兼容播放量为null** — 播放量不作为必要计算因子，传播系数用分享/点赞比替代
3. **0换算** — 每项直接评分，无需乘系数
4. **不重复** — 同一指标只在一个维度出现

## 边界与降级（异常处理）

| 场景 | 处理 |
|:---|:---|
| 数据服务指数未收录/未更新 | 平台指数维度得0分，其余三维度不受影响，报告中标注 |
| 近7天无作品 | 内容表现维度得0分，建议提示恢复更新节奏 |
| 播放量为null | 不影响评分，传播系数用分享/点赞比替代 |
| 账号昵称搜不到 | 提示改用抖音号精确查询 |
| 评分数据不全 | 逐项标注缺失指标，不阻塞整体评分 |

## 检查点

- 出报告前：人工核对关键数据（粉丝数/作品数/近7天表现）与平台展示一致
- 评分时：每项得分附计算过程，可追溯（不凭感觉打分）

## 快速体检示例

```
输入：某宠物账号（抖音号查询）
数据：粉丝 85万 / 获赞 3200万 / 作品 240条 / 近7天发布6条（黄金时段）/ 简介完整 / 数据服务指数 720

评分：
  账号体量：粉丝(9分) + 获赞(5分) + 获赞粉丝比 37.6(5分) = 19分
  内容表现：近7天均赞 3.2万(4分) + 均评 850(3分) + 均享 2600(4分) + 传播系数 8%(4分) = 15分
  运营活跃度：更新6条(6分) + 黄金时段(4分) + 简介完整(4分) + 作品240条(3分) = 17分
  平台指数：720(6分)
  综合：19+15+17+6 = 57分 → ⚠️ D级（亚健康）

建议：①优化视频前3秒吸引力提升互动 ②聚焦黄金时段发布 ③冲刺 60 分进入 C 级
```
