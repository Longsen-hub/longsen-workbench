# 运营方案生成器（ops-plan-generator）

运营方案生成引擎 · 独立 Skill · 四层技术架构（数据层 → 前置条件层 → 任务层 → 后端逻辑）

## 它能做什么

输入 9 项运营要素（需求/素材/内容类型/平台/风格/人群/关键词/对标账号/竞品），输出 12 部分完整运营方案：

主文案 + 备选标题×3 + 标签组 + 引擎融合 + 行业数据背书 + 竞品雷达对标 + 真实热点×3 + 爆款公式 + 结构说明 + 对标案例×3 + 发布策略 + 数据来源报告

## 特性

- **数据真实可溯**：所有引用（热点/案例/公式/竞品）带来源，禁止编造
- **前置条件门禁**：输入完整度/账号绑定/行业匹配/数据可用性四重校验
- **模板引擎**：10 风格 × 11 内容类型 × 10 平台 × 15 爆款公式，可扩展
- **配置外置**：数据源全部 env 可覆盖，迁移零改动

## 本发布包内容

本发布包为**方法论 + 集成契约文档**：

```
├── SKILL.md   # 方法论完整版：12部分输出结构 / 10风格×11类型×10平台×15公式模板表 / 前置条件C1-C4 / 集成契约
└── README.md  # 本文档
```

> 实现代码（CLI/引擎/模板脚本）由集成方按 SKILL.md 中的参考架构与集成契约自研；完整可运行实现见「全能版」配套能力。

## 集成方式

1. 按 SKILL.md「参考架构」落地模块（数据层/前置条件层/任务层/后端逻辑）
2. 按「集成契约」实现 CLI：`--keyword/--type/--platform/--style/--audience/--account/--rival/--request/--json`
3. 配置数据源：`OPS_REPORT31`（账号库）/ `OPS_HOTSPOT`（热点池）/ `OPS_DB`（我的账号）三环境变量
4. 自建回归测试：完整生成/行业不匹配/拦截/数据缺失容错
