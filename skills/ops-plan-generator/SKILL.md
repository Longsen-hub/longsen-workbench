# 运营方案生成器（ops-plan-generator）

## 定位

运营方案生成引擎 · 独立 Skill · 四层技术架构。输入运营需求与素材，输出可直接落地的完整运营方案。可经 CLI 被子 agent 调用，也可作为 Web 应用的后端引擎。

```
① 数据层(data_layer) → ③ 前置条件层(precondition) → ② 任务层(task_layer) → ④ 后端逻辑(engine)
```

## 参考架构（实现方可按此落地）

> 本发布包为**方法论 + 契约文档**（SKILL.md + README.md）。以下为完整实现时的参考目录与模块划分，集成方可按契约自研实现：

```
ops-plan-generator/
├── SKILL.md                    # 本文档（技能文档+调用协议）
├── README.md                   # 架构/数据源/前置条件/调用协议
├── config/config.json          # 配置：数据源路径(可env覆盖)/默认参数/任务参数
├── data/industry_words.json    # 行业词库（可扩展）
├── scripts/
│   ├── cli.py                  # CLI 入口（子agent 调用协议）
│   ├── data_layer.py           # ①数据层：数据源访问+可用性报告
│   ├── precondition.py         # ③前置条件层：C1-C4 校验
│   ├── task_layer.py           # ②任务层：任务创建/状态/结果/历史
│   ├── engine.py               # ④后端逻辑：三路匹配+文案拼装
│   └── templates.py            # 模板外置（风格/类型/平台/公式/结构）
└── tests/test_generator.py     # 回归测试
```

## ⭐ 数据从哪里来（数据层，只读）

| 数据 | 来源 | 内容 |
|:---|:---|:---|
| 账号库 | 环境变量 `OPS_REPORT31` 指定（账号数据文件，可配） | 多账号×多板块：公式/案例/统计/矩阵/策略/竞品 |
| 热点池 | 环境变量 `OPS_HOTSPOT` 指定（热点数据文件，可配） | 真实热点（可跨行业扩充） |
| 我的账号 | 环境变量 `OPS_DB` 指定（账号数据库，可配） | 账号表（基础信息，自动降级） |
| 素材 | 调用方上传（CLI 不传；Web 版存 static/uploads/） | 注入文案素材段 |

> 数据源全部经 config.json 配置、env 可覆盖——不写死路径，迁移即改配置。

## ⭐ 前置条件从哪里来（前置条件层）

| 条件 | 规则来源 | 行为 |
|:---|:---|:---|
| C1 输入完整 | 用户输入（需求/关键词至少一） | 拦截 400 |
| C2 账号绑定 | 绑定状态 | 未绑→提示 |
| C3 行业匹配 | `data/industry_words.json` 中**账号行业词**（需求须命中账号行业词才匹配，关键词优先） | 不匹配→解除锁定+提示 |
| C4 数据可用 | 数据层 availability 报告 | 空→提示 |

## 子 agent 调用协议（集成契约）

> 以下为 CLI 集成契约示例——实现方按此契约落地后，子 agent 可一键生成运营方案：

```bash
python3 scripts/cli.py --keyword 财税 --type 知识科普 --platform 抖音 --style 专业干货 \
                       [--audience 人群] [--account 对标账号] [--rival 竞品账号] \
                       [--request 运营需求] [--json]
```

**返回契约**（--json）：
```json
{"success": true,
 "main_copy": "...", "titles": [...], "tags": [...], "hotspots": [...],
 "engine": {"hotspot": "...", "formula": "...", "case": "...", "notes": ["前置条件提示"]},
 "formula_used": {...}, "industry": {...}, "rival": {...}, "formulas": [...], "cases": [...],
 "structure": {...}, "strategy": "...",
 "task": {"id": "ops-...", "status": "done"},
 "data_sources": {"accounts": 9, "rivals": 22, "hotspots": 405, "formulas": 34, ...}}
```
**错误契约**：`{"success": false, "error": "缺少运营需求或行业关键词，至少填一项"}`

## 输出结构（12 部分）

1. **主文案**：平台开头 → 账号公式钩子 → 类型结构 → 人群定位 → 账号策略 → 热点借势 → 需求 → 标注 → 风格 CTA
2. **备选标题×3**
3. **标签组**（平台标签 + 行业标签）
4. **引擎融合**：三路匹配 + 前置条件提示
5. **行业数据背书**
6. **竞品雷达对标**
7. **真实热点×3**
8. **爆款公式**
9. **结构说明**
10. **对标案例×3**
11. **发布策略**（平台时段）
12. **任务信息 + 数据来源报告**

## 边界（诚实标注）

- 账号库为单行业时（如财税），跨行业需求触发账号锁定解除+提示；需扩充对应行业账号库
- 热点池若为单行业资讯类，非本行业关键词命中率有限
- 文案为规则模板拼装（非 LLM 生成）；素材上传仅 Web 版支持
- 行业词库可扩展（财税/AI培训 等），扩展后需同步扩充账号库数据
