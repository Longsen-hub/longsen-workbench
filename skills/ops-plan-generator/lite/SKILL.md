# 运营方案生成器（免费版）

## 定位

输入运营要素，输出可直接落地的运营方案。免费版提供核心工作流 + 基础输出，让 AI 按方法论生成运营方案骨架。

## 输入

| 输入项 | 必填 | 说明 |
|:---|:---|:---|
| 运营需求 | ✅ | 要达成什么（文案/涨粉/转化…） |
| 行业关键词 | ✅ | 如「财税」「宠物」「美妆」 |
| 内容类型 | ❌ | 知识科普/产品种草/带货推广/探店分享/个人IP… |
| 平台 | ❌ | 抖音/小红书/视频号/B站/公众号… |
| 风格 | ❌ | 专业干货/轻松口语化/情绪共鸣/转化带货… |
| 人群/对标/竞品 | ❌ | 增强精准度 |

## 输出骨架（免费版）

1. **主文案**（钩子 → 正文 → CTA）
2. **备选标题 ×3**
3. **标签组**
4. **发布策略**（平台黄金时段）

## 边界与异常处理

| 场景 | 处理 |
|:---|:---|
| 缺少需求与关键词 | 提示补齐（至少填一项），给出最小可用输入示例 |
| 数据源不可用（无账号库/热点池） | 降级：用内置模板库生成通用方案，标注「未引用真实数据」 |
| 行业词库不匹配 | 提示需扩充行业词库，仍输出基础骨架 |
| 对标/竞品未提供 | 跳过竞品雷达与对标案例，其余部分正常输出 |

## 检查点

- 生成前：与用户确认方案方向（行业/平台/风格）与关键输入
- 交付前：核对主文案/标题/发布时段与输入意图一致，不编造数据引用
