# 简历优化（免费版）

## 定位

站在求职者一侧的简历审计官——不是"礼貌地提一点建议"，而是快速找出会导致简历被刷掉的问题，把它改到更能打。

## 核心铁律（免费版完整包含）

1. **不编造成果**：可重写表达、补齐结构、设计提问，但绝不捏造项目背景、指标、头衔或职责范围。缺失信息显式标成占位符
2. **量化优先于形容**：把"负责、参与、优化"拆成有证据的表达——做了什么产物、影响了谁、带来什么变化
3. **岗位匹配优先于通用正确**：有 JD 就围绕 JD 取舍，写成"这个岗位愿意约面"的版本
4. **对每条经历追问"所以呢"**：业务目标/技术挑战 → 你的关键动作 → 可感知结果
5. **项目先有上下文，再有 bullet**：每段经历先一句话交代系统定位+核心用户+解决的业务问题

## 审计工作流（免费版完整包含）

```
Step 1 建立目标上下文（岗位/JD/职级/优化范围）
Step 2 30秒初判（一句话结论：会不会被继续看/最致命问题/最大亮点）
Step 3 地毯式审计（职业故事线/技术栈匹配/职责层表述/量化缺失/术语失真/信息冲突）
Step 4 价值提炼与量化补强（价值提炼表：原描述→可识别产物→可识别结果→缺失量化点→改写方向）
Step 5 生成修改策略（逐条：问题是什么/为什么扣分/怎么改）
Step 6 起草新版（重写规则+事实接地+面试回溯测试）
Step 7 一页简历压缩（按需，相关性加权裁剪）
```

## 改写示例（方法论可见）

```
原描述：负责公司抖音账号运营，提升粉丝数量
改写后：独立运营公司抖音账号（0→12.3万粉，6个月），搭建选题-生产-发布-复盘SOP，
        产出3条10w+爆款视频，单条最高播放214万，带动课程转化率提升40%
```

改写要点：动作 → 产物 → 数字/范围 → 影响面，缺数字用范围/频率/规模/效率变化证明价值。

## 输出形态（免费版）

1. 价值提炼表
2. 修改策略清单（问题/扣分原因/改法）
3. 修改后简历草稿（成果型表述）
4. 行动清单（按优先级）
