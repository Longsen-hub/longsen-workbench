# ATS 可解析性检查清单（ATS Parseability Checklist）

招聘方系统（ATS/简历解析器）读的是 PDF/文档的**文本层**，不是渲染出来的页面。一份视觉上很好看的简历，解析出来可能是乱码、缺字、日期丢失。**视觉通过 ≠ 解析通过。**

---

## 前置工具

```bash
# macOS
brew install poppler

# Debian/Ubuntu
apt install poppler-utils
```

检查命令：

```bash
pdftotext -v        # 检查是否安装（ATS 文本层检查必备）
pdftotext -layout 简历.pdf 简历.txt   # 提取文本层
pdfinfo 简历.pdf    # 查看页数等元信息
```

如果 `pdftotext` 未安装：跳过机械检查并明示"降级模式"，改用视觉阅读 PDF 核对关键词覆盖。

---

## 一、PDF 文本可提取性

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 文本能提取 | `pdftotext` 输出非空，无 `(cid:NNN)` 标记、无 `�` 乱码、无明显缺段 |
| 2 | 联系方式是纯文本 | 邮箱、电话必须以文本出现，不能只存在于图标/超链接里（链接目标对 ATS 不可见） |
| 3 | 阅读顺序正确 | 提取顺序与视觉顺序一致。单栏布局安全；双栏/侧边栏可能交错串行——若错乱，用户在用可解析性换颜值，必须告知 |
| 4 | 日期可识别 | 每段经历有起止年份；**用 ASCII 连字符 `-`，不要用 en-dash `–`**（很多解析器只认 ASCII 连字符，`2016–2024` 会被当成没有日期范围） |
| 5 | 短合同写明确范围 | 少于一年的经历写 `2024年3月-2024年7月` 这类明确区间；裸写 `2024` 只有开始没有结束，导入时可能丢 |
| 6 | 无纯图片式简历 | 整页是图片转 PDF（或表格截图）无法解析，必须换可编辑源文件导出 |

### 日期检查的静默失败提醒

日期问题**静默失败**：文本层看起来完全正常，但导入系统时结束日期被丢、教育经历整段没导进去。所以第 4、5 项必须主动核对，不能因为"看起来没问题"就跳过。

## 二、关键词命中率

用 Step 0 提取的 JD required/preferred 关键词清单，逐词核对简历文本层（**用 JD 原文术语**，按 JD 语言核对）：

| 关键词 | 优先级 | 状态 | 备注 |
|--------|--------|------|------|
| ... | required/preferred | covered / synonym-only / missing(有但没写) / missing(真缺口) | 出现在哪 / 为什么缺 |

状态定义：

- **covered**：原文出现（或正常词形变化）
- **synonym-only**：概念存在但用了别的词。若 JD 原文术语真实适用，优先改为原文术语（ATS 匹配常是字面的，"MLOps" 标题比"模型部署"命中率高）
- **missing (有但没写)**：画像证明候选人有这技能，但简历没写 → 补进合适位置，优先补在经历 bullet（具体证据）而非技能列表（抽象声明），补完重新导出再查
- **missing (真缺口)**：真实缺口 → 保持缺失。**绝不堆砌没有的技能。** 缺口在求职信/沟通中诚实桥接，不在简历里硬塞

中文场景补充：中英混合 JD 要注意双语关键词；英文 JD 对中文简历是 synonym-only 降级，备注里写明语言差异。

## 三、标准段落结构

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 单栏布局 | 单栏优先，避免双栏/侧边栏/分栏错位 |
| 2 | 标准标题 | 工作经历/项目经历/教育背景/技能等段落标题清晰可辨，能被解析器识别为段落 |
| 3 | 无表格排版文字 | 不用表格/文本框排版正文（解析器会错位或丢失） |
| 4 | 字体嵌入完整 | 导 PDF 时嵌入字体，避免缺字/乱码 |
| 5 | 命名规范 | 文件名不含特殊字符；简历命名清晰（如 `张三-后端工程师-简历.pdf`） |

## 四、输出格式

```markdown
## ATS 检查结果

### 文本可提取性
- [PASS/FAIL] 文本提取无乱码
- [PASS/FAIL] 联系方式为纯文本
- [PASS/FAIL] 阅读顺序正确
- [PASS/FAIL] 日期 ASCII 连字符 + 起止齐全
- [PASS/FAIL] 非图片式简历

### 关键词覆盖
| 关键词 | 优先级 | 状态 | 备注 |
|--------|--------|------|------|
| ... | ... | ... | ... |

### 段落结构
- [PASS/FAIL] 单栏 + 标准标题 + 无表格排版

### 修复清单
1. [具体问题] → [具体修法]
```

## 五、常见修复

- 邮箱只在图标/链接里 → 改成纯文本打印在页面上
- 双栏解析错乱 → 改成单栏，或告知用户取舍
- 日期用 en-dash → 全部替换为 ASCII `-`
- 图片式简历 → 要求用户提供 Word/可编辑源文件重新导出
- 有技能没写 → 补进对应经历 bullet，重新导出重新验证
