# 技能缺口分析（Skill Gap Analysis）— P2

分析候选人画像与目标岗位之间的技能差距，输出**缺口热力图 + 学习计划**。P2 能力，在用户要求做差距分析或学习规划时使用。

---

## 一、输入

- 候选人画像：技能清单（每项带项目证据）+ 工作经历
- 目标岗位 JD：required / preferred 技能清单
- 五维评估结果（SKILL.md Step 3）：技术匹配分 + 缺口清单

## 二、产出 1：缺口热力图

| 技能 | JD 要求级别 | 当前水平 | 缺口级别 | 热度 | 证据位置 |
|------|------------|---------|---------|------|---------|
| ... | required/preferred | 主力/会用/了解/无 | 无缺口/可迁移/需补强/缺失 | 高/中/低 | 简历哪段能证明 |

分级规则：

**缺口级别**
- **无缺口**：已具备且简历有证据
- **可迁移**：相邻技能可迁移（如 Python → 其他语言、关系型 → NoSQL）
- **需补强**：会但不深，缺少能证明深度的项目证据
- **缺失**：完全不具备

**热度（对录用影响）**
- **高**：required 且是岗位核心能力
- **中**：required 但边缘，或 preferred 且核心
- **低**：preferred 且边缘

热力图排序：按热度降序 + 缺口级别从重到轻排，高热度缺失排最前。

## 三、产出 2：学习计划

按热度排序制定，每项包含：

```text
### [技能名]（热度：高 / 缺口：缺失）
- **目标**：[学会后能做什么，可验证]
- **时长**：[建议周期，如 2-4 周]
- **资源**：[教程/文档/练习项目，具体可执行]
- **验证方式**：[作品/测试/面试题/小型项目]
- **简历侧**：[缺失→不写进简历，面试用桥接话术]
```

优先级策略：

1. **高热度缺失** → 优先学习计划（课程 + 动手项目 + 验证）
2. **高热度需补强** → 强化计划（深入项目、开源贡献、把现有项目加深）
3. **中热度** → 可并行，低优先级
4. **低热度** → 可选，一般不动

## 四、产出 3：简历侧行动

- **有证据但简历没写** → 补进简历（具体 bullet，不是技能列表堆名词）
- **需补强的技能** → 用**真实项目**补证据（现有项目加深、真实开源贡献），不伪造
- **缺失技能** → 简历不写；面试被问到时用桥接话术（承认 → 相邻经验 → 学习路径）

## 五、输出格式

```markdown
## 技能缺口分析：[目标岗位]

### 缺口热力图
| 技能 | JD要求 | 当前水平 | 缺口 | 热度 | 证据位置 |
|------|--------|---------|------|------|---------|
| ... | ... | ... | ... | ... | ... |

### 学习计划（按热度排序）
[见上文格式，逐项列出]

### 简历侧行动
- [补写 / 加深 / 不写改桥接]

### 下一步（2-4 周内）
- [第一条可执行动作]
```

## 六、边界铁律

1. **学习计划是计划，不是已拥有技能**——绝不因为"正在学"就把技能写进简历
2. 不承诺学习时长与效果，只给建议周期
3. 每 2-4 周回访一次高热度缺口，验证进展后再决定是否调整简历策略
4. 缺口分析结果与五维评分联动：技术匹配分低时，先分清哪些缺口能快速补、哪些只能桥接，避免把简历改造成"承诺清单"
